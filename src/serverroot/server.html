Домашний веб-сервер mkolyadin.ru

Описание сервера: - Сервер написан на языке С. - Низкоуровневая реализация - работа c памятью, сокетами и пр. - Используется минимальный набор библиотек. - Сервер работает на базе VM Centos 7.

Функционал сервера: - Обработка HTTP-запросов. - TLS-шифрование, благодаря прокси-серверу NGINX. - Кеширование файлов (LRU cache). Хэш таблицы и связанные списки. Срок годности кеша. - Многопоточность (pthread.h). Блокировка файлов и чистка памяти. - Защита от атак. Фильтрация запросов.

Безопасность сервера. Исходный код. Основа проекта.
