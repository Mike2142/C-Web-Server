Custom Web Server for mkolyadin.dev

Architecture Overview:

  • Developed in C language.
  • Low-level implementation: direct memory management, socket programming.
  • Minimalist approach with a limited set of external libraries.
  • Hosted on a CentOS 7 virtual machine.

Core Functionality:

  • High-performance HTTP request processing.
  • TLS encryption via NGINX reverse proxy.
  • Built-in LRU caching system: hash tables, linked lists, and TTL.
  • Multithreaded execution (pthread.h) with file locking and memory cleanup.
  • Security hardening and request filtering logic.
