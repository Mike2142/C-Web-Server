Сервер Jenkins.

Окружение: Docker compose, VM Linux CentOS.

Пайплайн CI/CD для приложения Java Maven. - Загрузка Java-кода из Github. - Стадия BUILD: Сборка приложения в jar файл (mvn -B -DskipTests clean package). - Стадия TEST: Проводит тесты JUnit (mvn test), сохраняет результаты (XML) и выводит их в кабинете Jenkins. - Стадия DELIVER: Скрипт (deliver.sh) сохраняет приложение (jar) в репо для Maven-пакетов и запускает его (java jar).

Кабинет Jenkins. Пайплайн CI/CD.
