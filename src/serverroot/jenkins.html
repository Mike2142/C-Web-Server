Сервер Jenkins.

Локальный сервер Jenkins в сервисе docker compose. Сервер содержит пайплайн приложения Java Maven.

Содержание пайплайна. - Загрузка Java-кода из GitHub. - Стадия BUILD: Сборка приложения в jar файл (mvn -B -DskipTests clean package). - Стадия TEST: Проводит тесты JUnit (mvn test), сохраняет результаты (XML) и выводит их в кабинете Jenkins. - Стадия DELIVER: Скрипт (deliver.sh) сохраняет приложение (jar) в репо для Maven-пакетов и запускает его (java jar).
