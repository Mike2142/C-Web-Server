Сервер Jenkins.

Окружение: Docker compose, VM Linux CentOS.

Пайплайн CI/CD для приложения Java Maven. - Загрузка Java-кода из Github. - Стадия BUILD: Сборка приложения в jar файл (mvn -B -DskipTests clean package). - Стадия TEST: Проводит тесты JUnit (mvn test), сохраняет результаты в формате XML и выводит их в кабинете Jenkins. - Стадия DELIVER: Скрипт доставки (deliver.sh). Скрипт сохраняет приложение (jar) в локальный репо для Maven-пакетов и запускает приложение (java jar).
