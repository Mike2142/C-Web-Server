Проекты Python Django.

Сбор и обработка писем из ящиков MS Exchange. Экспорт в систему IBM Fault Management. - Интерактивная карта сети. - Backend. Импорт и обработка данных об оборудовании, сохранение данных в БД. Предоставление API. - Frontend (Angular). Интерактивная карта сети, статистика и данные об авариях в реальном времени.
